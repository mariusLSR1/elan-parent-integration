Test iframe Élan

Page parent autonome pour tester le chargement iframe, les messages elan:resize et le thème envoyé via elan:set-theme.

Ouvrez cette page via HTTP. Le chargement depuis file:// ne peut pas afficher l’app en iframe à cause de la règle CSP frame-ancestors. Depuis la racine du dépôt : npm run dev:demo puis http://localhost:4000/ (Élan sur npm run dev, port 3000).
